# Commands

Generated by `scripts/gen-reference.sh` from `make help`; run `make docs` after changing the `Makefile`.
Set `PRESET`, `BASE`, or `FUZZ_SECONDS` on the command line, as in `make lint PRESET=asan`.

| Command | What it does |
| --- | --- |
| `make help` | List every target |
| `make bootstrap` | Install the toolchain, tools, and vcpkg once per machine |
| `make setup-repo` | Create the ci:* labels, protect main with the status check, and squash-merge only; GitHub CLI |
| `make dev` | Configure, build, and run unit and integration tests of the debug build |
| `make functional` | Build dev and run the black-box tests of the apps |
| `make stress` | Build dev and run the long-running tests labeled stress |
| `make release` | Configure, build, and test the optimized build, with LTO, for this machine's CPU |
| `make relwithdebinfo` | Configure, build, and test at -O2 with debug info and frame pointers |
| `make profile` | Configure, build, and test the release flags with debug info and no LTO, for perf |
| `make cxx26` | Configure, build, and run unit and integration tests in C++26 |
| `make asan` | Configure, build, and test under AddressSanitizer and UBSan |
| `make tsan` | Configure, build, and test under ThreadSanitizer |
| `make msan` | Configure, build, and test under MemorySanitizer; Linux, after scripts/build-msan-libcxx.sh |
| `make valgrind` | Build dev and run its unit and integration tests under Valgrind memcheck; Linux |
| `make coverage` | Configure the coverage preset, run its tests, and write build/current/coverage/lcov.info |
| `make bench` | Build the bench preset and run every benchmark, writing JSON to build/current/bench/ |
| `make bench-compare` | Run the benchmarks at BASE (default main) and here, and print the difference |
| `make fuzz` | Build the fuzz preset and fuzz every harness for FUZZ_SECONDS (default 30) each |
| `make lint` | Configure PRESET (default dev) and run clang-tidy over it; any finding fails |
| `make format` | Rewrite every C++ and CMake file with clang-format and gersemi |
| `make format-check` | Fail on any C++ or CMake file that make format would change; changes nothing |
| `make docs` | Regenerate docs/reference/commands.md and presets.md from make help and CMakePresets.json |
| `make build` | Build PRESET (default dev) after it has been configured |
| `make test` | Run the test preset PRESET (default dev) after it has been built |
| `make clean-all` | Delete every build directory |
